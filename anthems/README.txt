Drop your anthem audio here. Any filename works.

The dashboard looks for a file whose name mentions the club:

  Real Madrid        anything containing "madrid" or "hala"
  Manchester United  anything containing "united" or "glory"

So "Hala Madrid...y nada mas.mp3" and "Glory Glory Man United.mp3" are
both picked up as they are - no renaming needed.

To force one exact file when several could match, name it:

  real_madrid.mp3
  man_united.mp3

An exact name always wins over a keyword match.
.m4a, .ogg, .wav and .opus work too.

Which one played? The player in the corner of the page names the file.
